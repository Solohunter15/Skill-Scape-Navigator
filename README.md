## 🌟 Centerpiece Features

### 1. 🌌 3D Celestial Skill Constellation (WebGL / Three.js)
- **Interactive Celestial Starscape**: 1,800 particle stars with cosmic nebula depth fog and 360° `OrbitControls` (pan, tilt, zoom).
- **6 Domain Nebulae**:
  - 🔷 **Frontend**: React 18 / Next.js, Advanced TypeScript, State Management, Core Web Vitals.
  - 🟣 **Backend**: Node.js & Async Runtimes, PostgreSQL, REST/gRPC/GraphQL, Event Streaming (Kafka).
  - 🔵 **Cloud & DevOps**: Kubernetes, AWS Cloud Architecture, CI/CD & Terraform, Observability & SRE.
  - 🟢 **AI & Data**: LLM Agents & RAG, Python & Vector DBs, AI Safety & Guardrails.
  - 🟡 **System Architecture**: Distributed Systems, Caching & Consistency, Zero-Trust Security.
  - 🔴 **Leadership**: RFCs & Architectural Governance, Engineering Mentorship, Tech Strategy.
- **Node Luminosity & Scale**: Node sizes and emissive glow scale dynamically based on mastery level (0–100).
- **Constellation Relationship Links**: Dynamic lines connecting prerequisite and cross-domain dependencies.
- **Interactive Skill HUD**: Hover or click any star to inspect XP progress, prerequisites, market demand percentile, and trigger instant practice boosts.

### 2. 🎯 Dynamic Career Gap Matrix & Benchmark Simulator
- **Elite Role Benchmarks**: Compare your competency footprint against verified criteria for:
  - **Staff Platform Architect** (Median $245,000)
  - **Principal AI Engineer** (Median $270,000)
  - **Senior Full-Stack Engineer** (Median $180,000)
  - **Director of Engineering** (Median $295,000)
- **Readiness Scoring (%)**: Algorithmic weighting calculating your exact readiness match against the target role.
- **Skill Deficit Matrix**: Pinpoints exact competency point gaps with 1-click practice and scenario shortcuts.
- **Compensation Upside Forecaster**: Visualizes 25th, 50th, and 90th percentile market salary distributions with annual upside deltas (e.g., +$65,000/yr).
- **Promotion Milestones**: 3 multi-month strategic milestones required to reach promotion.

### 3. ⚔️ Architectural Quests & Level-Up Engine
- **High-Stakes Decision Arenas**: Test engineering intuition against real-world production challenges:
  - *Black Friday Redis Cache Stampedes* (Mutex locking vs XFetch algorithm)
  - *Kubernetes Pod OOMKilled Cascades* (Guaranteed QoS & PriorityClasses)
  - *Production RAG Hallucination Mitigation* (Hybrid Search + Cross-Encoder reranking)
  - *Trading Dashboard Table Virtualization* (TanStack Virtual + atomic signal isolation)
- **Real-Time Level-Up Celebrations**: Solving scenarios rewards verifiable XP that dynamically upgrades your skills and illuminates your 3D star.

### 4. ⚡ AI Precision Nudge Center
- **Proactive Micro-Interventions**: Actionable daily nudges categorized by urgency (High, Medium, Low).
- **Contextual Signals**: Derives recommendations from simulated code review bottlenecks, calendar congestion, and market skill deficits.

### 5. 📊 Executive Career Analytics & Cryptographic Career Passport
- **Cross-Domain Skill Radar**: 6-axis Recharts radar comparing current footprint against target role benchmark.
- **XP Velocity Area Chart**: 6-month historical tracking of competency velocity and learning trajectory.
- **Verified Career Passport**: Holographic credentials modal displaying Navigator ID, Tier level, and top competencies with an **Export JSON Passport** feature.

### 6. 🔌 Developer Ecosystem Integrations & Custom Skill Builder
- **Platform Telemetry Hub**: Interactive connection toggles for GitHub Enterprise, Google Calendar, Jira/Linear, Coursera, and Slack with a live event ingestion ticker.
- **Custom Skill Builder**: Modal allowing engineers to add custom skills (Rust, WebAssembly, Solidity) with custom level sliders and 3D coordinate placement.

## 🚀 Getting Started

### Prerequisites
- Node.js `v18.0.0` or higher
- npm (or pnpm)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Solohunter15/Skill-Scape-Navigator.git
   cd Skill-Scape-Navigator
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## 🧪 Testing & Quality Assurance

Run the automated Vitest test suite:
```bash
npm run test
```

Run TypeScript validation:
```bash
npm run typecheck
```

Build for production:
```bash
npm run build
```

## 🌐 Deploying to Vercel

This repository includes a pre-configured [`vercel.json`](./vercel.json) optimized for Vite single-page application routing.

1. Import this repository into [Vercel](https://vercel.com/new).
2. Set **Framework Preset** to **`Vite`** (or **`Other`**).
3. Build command: `npm run build`
4. Output directory: `dist`
5. Click **Deploy**.
